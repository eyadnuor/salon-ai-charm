# صالون AI

أنشئ تطبيق SaaS عربي متكامل باسم «صالون AI» لإدارة المتاجر ومحلات الكوافير ومراكز التجميل، ويكون تطبيق ويب responsive وRTL بالكامل، بتصميم احترافي حديث وسهل الاستخدام. استخدم full-stack TypeScript مع Tailwind وshadcn/ui وبنية قابلة للتوسعة.

الهدف: منصة متعددة المستأجرين Multi-tenant يبيع مالكها اشتراكات لأصحاب المتاجر ومحلات الكوافير، مع أربعة أدوار وتجارب منفصلة: مالك المنصة، التاجر، الموظف، العميل.

أنشئ صفحات الدخول والتسجيل واستعادة كلمة المرور، مع شاشة لاختيار/توضيح الدور وحسابات تجريبية لكل دور. استخدم بيانات تجريبية واقعية بالعربية واجعل كل التنقلات والأزرار الرئيسية تعمل. إن لم تكن قاعدة البيانات/المصادقة متاحة الآن، نفّذ Mock data وواجهات كاملة قابلة للاستعراض مع طبقة services واضحة لاستبدالها لاحقاً بقاعدة بيانات حقيقية.

1) الموقع العام التسويقي:
- Hero قوي يشرح إدارة الصالون والحجوزات بالذكاء الاصطناعي.
- المزايا، كيف تعمل المنصة، لقطات/بطاقات للمنتج، آراء العملاء، الأسئلة الشائعة، CTA.
- صفحة أسعار بثلاث باقات: أساسية، احترافية، أعمال، مع شهري/سنوي ومقارنة مزايا.
- صفحات من نحن، تواصل معنا، الشروط والخصوصية.
- زر تجربة مجانية وزر تسجيل الدخول.

2) لوحة مالك المنصة Super Admin:
- نظرة عامة: MRR/ARR، عدد التجار، الاشتراكات النشطة، التجارب المجانية، معدل الإلغاء، الإيرادات مع رسوم بيانية.
- إدارة التجار وفتح ملف كل تاجر، تفعيل/تعليق الحساب.
- إدارة الخطط والأسعار والمزايا والكوبونات العامة.
- الاشتراكات والفواتير والمدفوعات وحالاتها.
- تذاكر الدعم وإعدادات المنصة والإشعارات.
- صفحة AI Support لمتابعة محادثات المساعد، معدل الحل، التصعيد للبشر، قاعدة المعرفة.

3) لوحة التاجر:
- Dashboard بإحصاءات حجوزات اليوم، الإيراد، العملاء الجدد، الموظفين الحاضرين، الخدمات الأكثر طلباً وتنبيهات المخزون.
- إعدادات الموقع/واجهة الحجز: محرر ألوان وخطوط واستايل وشعار وصورة غلاف، معاينة فورية، رابط/slug خاص بالمتجر، ساعات العمل والسياسات.
- الموظفون: قائمة وملفات وصلاحيات وجداول عمل وعمولات ومؤشرات أداء.
- العملاء: CRM بملفات العملاء، سجل الحجوزات والملاحظات والإنفاق والنقاط والتصنيفات.
- الحجوزات: تقويم يومي/أسبوعي/شهري، قائمة، إنشاء وتعديل وإلغاء، حالات مؤكد/بانتظار/مكتمل/ملغي، تعيين موظف وخدمة، بحث وفلاتر.
- المحافظ: أرصدة العملاء، الحركات، الشحن والاسترداد.
- الكوبونات: إنشاء كوبون، نوع الخصم، الصلاحية، الحد الأدنى، عدد الاستخدامات والحالة.
- النقاط والولاء: قواعد اكتساب واستبدال النقاط، المستويات وسجل العمليات.
- الخدمات: فئات وخدمات، مدة وسعر وصورة والموظفون المتاحون والحالة.
- المخزون: المنتجات والكميات والحد الأدنى والموردون وحركات المخزون وتنبيهات النفاد.
- الحسابات: إيرادات ومصروفات وفواتير وتقارير وأرباح/خسائر قابلة للتصفية.
- الرواتب: رواتب وعمولات وخصومات ومكافآت ومسيرات الرواتب.
- الحضور والانصراف: تسجيل حضور، جداول، تأخير، إضافي وتقارير.
- المدفوعات الإلكترونية: واجهة إعداد Stripe/PayPal وبوابات عربية كخيارات UI، مفاتيح مخفية، وضع اختبار/إنتاج، webhook status وسجل المعاملات. لا تستخدم مفاتيح حقيقية.
- الاشتراك والفواتير الخاصة بالتاجر.
- الإعدادات العامة والإشعارات والصلاحيات.
- إعادة ضبط المصنع: صفحة خطر منفصلة مع شرح ما سيُحذف، كتابة اسم المتجر للتأكيد، مربع تأكيد وخطوتين، واجهة فقط وآمنة في النسخة التجريبية.

4) لوحة الموظف:
- ملخص يوم العمل، حجوزاتي القادمة، تقويم شخصي.
- تسجيل الحضور والانصراف.
- العملاء المعيّنون، الخدمات التي يقدمها، العمولات والراتب.
- طلب إجازة، الإشعارات والملف الشخصي.
- صلاحيات محدودة وواضحة، دون الوصول لإعدادات التاجر الحساسة.

5) لوحة العميل:
- اكتشاف/صفحة المتجر، اختيار خدمة ثم موظف ثم موعد ثم تأكيد الحجز في flow واضح.
- حجوزاتي مع إعادة الحجز والإلغاء حسب السياسة.
- المحفظة، الكوبونات، النقاط والمستوى والمكافآت.
- المدفوعات والفواتير، الإشعارات، الملف الشخصي.
- مساعد دعم AI عربي كزر محادثة ثابت يجيب عن الخدمات والمواعيد والسياسات، يقترح مواعيد، يجمع تفاصيل المشكلة، ويوفر خيار «التحدث مع موظف»؛ استخدم ردوداً تجريبية ذكية وقاعدة معرفة mock بدون استدعاء API خارجي.

التصميم وتجربة الاستخدام:
- RTL حقيقي مع خط عربي جميل (مثل Tajawal أو Cairo) وواجهة نظيفة فاخرة مناسبة للصالونات، ألوان أساسية بنفسجي داكن/وردي هادئ مع إمكانية تغييرها من إعدادات التاجر.
- Sidebar قابلة للطي، top bar، breadcrumbs، بحث عام، مركز إشعارات، قوائم وفلاتر وجداول وempty/loading/error states وtoasts وdialogs.
- استخدم رسومًا بيانية وبطاقات KPI، ولا تترك صفحات placeholder فارغة.
- دعم الهاتف والتابلت وسطح المكتب، مع mobile navigation مناسبة.
- اهتم بإمكانية الوصول والتباين وحالات focus.
- أنشئ role switcher تجريبي ظاهر ليسهل استعراض اللوحات الأربع.

البيانات والبنية:
- نمذجة واضحة للكيانات: tenants, users, roles, employees, customers, services, bookings, wallets, wallet_transactions, coupons, loyalty_points, inventory_items, stock_movements, expenses, payroll, attendance, subscriptions, invoices, payments, support_conversations.
- اعزل بيانات كل تاجر مفاهيمياً بواسطة tenant_id.
- أنشئ صفحة 404 ومسارات محمية شكلياً حسب الدور.
- اجعل الواجهة كاملة وقابلة للنقر والاستعراض، مع بيانات Demo عربية متناسقة، وليس مجرد صفحة landing.

ابدأ ببناء النسخة الكاملة القابلة للتجربة، ثم شغّل فحصاً بصرياً وتأكد أن المسارات الأساسية تعمل دون أخطاء.
